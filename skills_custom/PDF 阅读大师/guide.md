【PDF 阅读大师 — 完整操作指南】

## 可用工具
- **pdf_load**: 加载 PDF 文件，返回页数、元数据、目录结构和是否有文本层
- **pdf_read_page**: 读取指定页码的文本内容
- **pdf_search**: 在 PDF 中搜索关键词，返回匹配的页码和上下文
- **pdf_metadata**: 提取 PDF 元数据（标题、作者、主题、创建日期等）
- **pdf_toc**: 提取 PDF 目录/书签结构

## 执行策略
1. **先加载后操作**: 使用 pdf_load 获取 PDF 概览信息，再根据需求调用其他工具
2. **按需读取**: 不要一次性读取所有页面，按用户需求逐页或分段读取
3. **搜索优先**: 当用户询问特定内容时，先用 pdf_search 定位，再读取相关页面
4. **安全路径**: PDF 路径必须是本地绝对路径，不支持 URL 远程加载

## 最佳实践
- 读取大 PDF（>100页）时，先通过 pdf_load 获取总页数和目录结构
- 搜索时指定合理的 max_results（默认10条），避免返回过多结果
- 对于扫描版 PDF（无文本层），pdf_load 会返回 has_text=false，需提示用户
- 提取元数据时优先展示 title、author、pages 等关键信息

## 典型场景
- "帮我看看这个 PDF" → pdf_load("D:/docs/论文.pdf")
- "翻到第5页" → pdf_read_page("D:/docs/论文.pdf", 5)
- "搜索'神经网络'相关内容" → pdf_search("D:/docs/论文.pdf", "神经网络")
- "这个文档是谁写的" → pdf_metadata("D:/docs/论文.pdf")
- "显示目录" → pdf_toc("D:/docs/论文.pdf")

## 错误处理
- 文件不存在 → 返回友好提示，引导用户确认路径
- 加密 PDF → 提示文件受密码保护
- 无文本层 → 提示扫描版 PDF 无法提取文本
- 超出页数范围 → 提示有效页数范围
